저장 초안 확인

모든 영역의 입력을 먼저 저장하거나 취소하세요. 사전 검사는 저장본의 구조 진단이며 품질 통과·검수 요청·공개가 아닙니다.

검수 요청 · 초안 반환

서버 권한 응답을 확인하고 있습니다. 쓰기는 아직 허용되지 않습니다.

현재 권한과 상태는 별도 조건입니다. 모든 변경은 서버가 다시 검증합니다. 공개 권한이 있어도 이 화면은 승인·공개를 제공하지 않습니다. 명시 조회·동의·전송과 응답 반영 때 계정과 고정 절대 기한을 다시 확인합니다. 신원 변경·확인 실패 시 이전 입력과 민감 열람을 폐기합니다.

저장 초안의 검수 요청

편집 권한과 활성 DRAFT·현재 사본 없음이 필요합니다. 모든 원고와 자식 자료의 미저장 입력을 먼저 저장하거나 취소하세요. 불변 사본과 서버 구조 검사를 만들며 품질 승인이 아닙니다. 확정 거절은 현재 GET·비교 수락으로 종료한 뒤 수정·저장하고 새 요청을 결정하세요. 응답 유실·형식 오류는 새 키로 바꾸지 않으며 원래 키·본문만 재확인합니다. 같은 신원의 CSRF 거절도 원래 의도를 유지합니다.

작성자 철회 · WITHDRAW

편집 권한으로 현재 REVIEW/READY를 반환합니다. 사유는 AUTHOR_REVISION입니다. 원고와 미저장 입력은 유지됩니다.

검수자 수정 요구 · CHANGES_REQUIRED

현재 전역 REVIEW와 같은 사건 REVIEW 관계가 모두 필요합니다. 소유자도 별도 검수 권한이 필요하며 선택한 역사 사본은 반환하지 않습니다.

확인 참조는 사용자가 확인한 비개인 영문·숫자·밑줄·하이픈 8~64자입니다. 외부 증명을 자동 조회하거나 참조를 생성하지 않습니다. 반환 응답 유실은 재전송하지 않고 현재 GET·비교만 제공합니다. DRAFT 조회는 이 요청의 성공 증거가 아닙니다. 반환 입력은 비우거나 확정 영수증의 값으로 되돌리면 미저장 상태가 해제됩니다. 원고·반환 입력·미확정 전환은 이 페이지 메모리에만 남습니다. 이탈 경고에서 떠나기를 선택하면 폐기되며 복원되지 않습니다. 입력을 비우거나 현재 GET을 수락해도 미확정 전환이 성공으로 바뀌거나 사라지지는 않습니다.

공개본에서 새 초안 만들기

선택 버전은 복제 후보입니다. 현재 공개본과 같은지, 진행 중인 DRAFT/REVIEW/READY가 있는지는 요청 시 서버가 잠금 아래 확인합니다. 활성 사건·버전과 사건 편집 권한이 필요하며 CREATE·검수·공개 권한, 최근 재인증·엔진 가용성·품질 통과는 복제 조건이 아닙니다.

이어받는 자료와 초기화되는 기록

공개 사본의 기본·정답·해설과 활성 자식 자료 11종을 새 식별자로 복사합니다. 원고·코드·관계는 유지하고 현재 제작 정책을 적용합니다. 새 버전은 DRAFT·수정번호 0·현재 사본 없음으로 시작합니다. 검수·실행·사람 확인·READY 근거는 승계하지 않습니다. 기존 공개본·노출·진행 게임과 이 화면의 미저장 입력은 바꾸지 않습니다.

후보 조회는 원고·쓰기 기준·다른 미확인 의도를 갱신하지 않습니다. 응답 유실은 새 키로 복구하지 않습니다. 재확인은 원래 요청이 미확정이면 새 초안을 실제로 생성할 수 있습니다. 키·본문·영수증은 이 페이지 메모리에만 남으며 이탈 시 폐기됩니다. 성공해도 자동 이동하지 않습니다.

복제 요청 전입니다.

    확인된 작업 버전 열기

    저장 검수 자료 열람

    제작자 편집기에 포함된 열람 영역입니다. 주변 원고에는 정답과 제작자 비밀이 남아 있으므로 독립된 역할 전용 화면이 아닙니다. 조회마다 서버가 접근권을 확인합니다. 아래 수동 의견 추가는 모델 실행·품질 인증·공개가 아니며 위의 검수 요청·반환과도 구분됩니다.

    마지막 상세 조회로 확인한 현재 버전

    쓰기 비교와 별도로 현재 열람 기준만 다시 확인할 수 있습니다.

    열람 기준 재조회는 원고 입력·쓰기 수정번호·저장 잠금·사람 확인 영수증을 변경하지 않습니다. 저장 재개는 기존 최신본 비교·수락과 별개입니다.

    검수 사본 이력 · 원문 없는 목록

    서버 ID 내림차순, 한 번에 20건입니다. 첫 행이 현재 회차라는 뜻은 아닙니다.

    아직 조회하지 않았습니다.

    선택한 불변 사본 · 목록에서 확인한 메타데이터

    선택만으로 원문·근거·미리보기를 불러오지 않으며 미저장 편집 입력은 유지됩니다.

    선택 사본의 제작자 민감 저장 원문

    SR04 응답 전체의 원래 JSON 텍스트(snapshot와 payload)입니다. 정답·정책·세 영역과 열한 자료 배열을 포함하며 현재 테이블로 재구성하지 않습니다. null·빈 문자열·배열 순서·큰 정수를 그대로 표시합니다.

    아직 조회하지 않았습니다.

    선택 사본의 저장 검수 근거 · 민감 자료

    SR06 응답 전체의 원래 JSON 텍스트입니다. evidenceData는 저장 wrapper가 아닌 근거 details입니다. 서버 순서와 과거 FAIL·selfReviewYn을 유지합니다. 이 페이지에 없는 종류는 통과나 미실시로 확정하지 않습니다. 한 페이지는 전체 검수 근거가 아니며 다음 조회는 앞 페이지를 대체합니다.

    아직 조회하지 않았습니다.

    선택 사본의 실행 지적 이력 · 읽기 전용

    저장된 BATCH 지적의 허용 메타데이터만 읽습니다. 매 페이지 현재 전역 REVIEW와 활성 사건 REVIEW 관계가 모두 필요합니다. 소유·편집·공개 권한은 대체하지 않습니다. 과거 사본도 조회할 수 있으며 현재 상태·runtime 가용성은 이력 조회 조건이 아닙니다. 빈 페이지는 전체 이력 없음·통과·치명 지적 없음·해소·READY·공개 가능의 증거가 아닙니다. 다음 조회는 앞 페이지를 대체합니다.

    아직 조회하지 않았습니다.

    현재 REVIEW · BATCH 지적 해소

    조회한 현재 사본의 OPEN INFRA / GRADING만 새 해소 대상으로 선택합니다. CONTENT·OBSERVATION·RESOLVED와 과거 이력은 읽기 전용입니다. 실제 후속 batchKey와 비개인 확인 참조를 직접 입력하세요. 조회는 관측일 뿐이며 현재 전역·사건 REVIEW 자격과 증거는 POST에서 서버가 판단합니다. 원고 수정번호를 올리거나 품질·READY·공개·운영 효력을 승인하지 않습니다.

    선택한 지적 없음

    사유는 선택한 지적 종류에 결속됩니다. targetReviewId는 null입니다.

    아직 조회하지 않았습니다. 자동 조회하지 않습니다.

    전송하지 않았습니다.

    결과 미확인 중 새 입력은 별도로 보존합니다. 재확인은 현재 입력이 아닌 원래 경로·키·본문만 전송하며 최초 요청이 저장되지 않았다면 실제 해소할 수 있습니다. 현재 GET·RESOLVED 이력은 유실 요청의 영수증이 아닙니다. 페이지를 떠나거나 명시 폐기하면 메모리의 재확인 의도를 잃습니다.

    MODEL / APPROVAL 의견 추가

    실제로 확인한 근거만 직접 입력하세요. 모델 실행이나 사람 승인을 자동 생성하지 않습니다. 새 기록은 수락한 상세의 활성 REVIEW, 현재 사본 선택과 현재 검수 권한이 모두 필요하며 서버가 재인가합니다. sourceRev·열람 전용 GET·과거 영수증은 쓰기 기준이 아닙니다.

    근거 입력 계약과 미실시 안내

    MODEL 근거 있음은 실제 모델·effort·실행 참조·별도 문맥 true가 필요합니다. 새 PASS는 gpt-6-astra / medium과 미해결 0건입니다. APPROVAL은 모델·effort·실행 참조·별도 문맥을 모두 명시적 null로 선택하며 PASS는 미해결 0건입니다. 근거 없음은 INCOMPLETE만 가능하고 모든 nullable 항목은 null, 비고와 근거 설명에는 정직한 미실시 사유가 필요합니다. 확인 시각은 실제 UTC이며 미래 여부의 최종 기준은 서버 시각입니다. 참조 주소를 자동 조회하지 않습니다.

    형식 2의 해결 항목은 같은 사본·같은 종류의 이전 FAIL/INCOMPLETE만 대상으로 합니다. PASS 외에는 비워 두세요. 이전 행은 수정하지 않으며 화면에 보인 이력이 전체라는 뜻도 아닙니다.

    형식 2 해결 항목 · 최대 100개

    응답 유실·503·잘못된 성공 응답은 결과 미확인입니다. 재확인은 읽기 전용 조회가 아니라 원래 추가가 실행될 수 있는 POST입니다. SR06 이력에는 요청 키가 없어 이전 요청의 소유권·실패를 증명하지 못합니다. 자동 재전송·자동 민감 이력 조회는 없습니다. 원래 키와 본문은 이 페이지 메모리에만 남고 명시 폐기·이탈 후 복구되지 않습니다. current/replayed는 품질·현재 쓰기 자격이 아닙니다.

    저장 자료의 서버 미리보기 투영

    로컬 미저장 입력이 아닌 저장 DRAFT 또는 선택 사본만 조회합니다. ROLE은 서버가 허용한 해당 역할 자료, REVEAL은 종료 해설입니다. 역할 코드의 존재·활성은 서버가 검사합니다. 게임·힌트 소비·블라인드 테스트 실적을 만들지 않으며 원문 속 주소나 마크업도 문자로만 표시합니다.

    DRAFT 출처는 활성 사건·활성 DRAFT 버전이며 현재 사본이 없을 때만 조회합니다.

    영문 대문자·숫자·밑줄 1~32자. 공백을 자동 제거하거나 코드를 변환하지 않습니다.

    아직 조회하지 않았습니다.

    개정 대조 · 저장 전 확인

    서로 다른 기록을 확인하세요

    이전 확인본, 현재 입력, 서버 최신본을 나란히 대조하세요. 비교 완료는 새 수정번호의 사용만 허용하며 저장하거나 자동 병합하지 않습니다.

    02

    관계와 공개 소개 · 제작자 비밀 분리

    사건 자료

    필요한 자료부터 자유롭게 작성하세요. 목록은 키와 상태만 보여 주며 선택한 자료만 열람합니다.

    목록을 조회하거나 새 인물을 작성하세요.

    선택한 인물의 기록

    코드는 영문 대문자·숫자·밑줄 1~32자이며 생성 뒤 고정됩니다. 이름은 필수이고 공개 소개·비밀 원고는 각각 8,000자까지 작성할 수 있습니다.

    논리 삭제는 원고 저장과 별개입니다. 활성 참조를 먼저 해제하세요. 삭제된 키도 예약되며 같은 자료를 복원할 수 있습니다.

    03

    제작자 전용 · 플레이어에게 표시되지 않음

    진상과 정답

    범인·수법·시간·동기의 연결을 기록합니다. 범인은 같은 버전의 활성 인물 코드만 지정할 수 있습니다.

    04

    종료 후 공개용 원고

    종결 해설

    조사로 드러난 사실을 연결해 설명합니다. 현재는 편집 원고이며 저장만으로 공개되지 않습니다.

    작성 기준 · 읽기 전용

    난이도 저장 후 적용되는 서버 정책입니다.

    작성 확인 0건 · 저장은 가능하며 검수 통과를 의미하지 않습니다.

    미저장 입력은 현재 페이지에만 있습니다. 새로고침·이동하면 사라질 수 있으며 자동 저장은 하지 않습니다.

    사건 자료를 표시할 수 없습니다

    사건 목록으로 이동
